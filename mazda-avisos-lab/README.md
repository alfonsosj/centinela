# Mazda Avisos Lab 0.2
Aplicación experimental auxiliar. NO modifica la app oficial de Mazda.
Lee los textos visibles del Centro de Mensajes mediante accesibilidad solo mientras la pantalla esté abierta. No tiene permiso INTERNET; no controla el coche ni obtiene tokens.
Primera lectura: importa avisos existentes sin notificar. En las siguientes lecturas muestra notificaciones para nuevos avisos reconocidos.
La app es experimental y no debe utilizarse como único sistema de alertas de seguridad.
Instalación: descargar artefacto Mazda-Avisos-Lab-APK desde GitHub Actions, extraer app-debug.apk, instalar y permitir accesibilidad y notificaciones.
